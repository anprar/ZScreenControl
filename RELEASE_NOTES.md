ZScreenControl v0.2.0 — layar tidur tepat waktu (gratis, tanpa iklan).

## Fitur baru di v0.2.0

- **Jadwal otomatis** — atur jam + hari (Room + AlarmManager tepat waktu, bertahan setelah reboot).
- **Timeout per aplikasi** — pilih aplikasi + durasi pemakaian; layar mati otomatis saat batas habis (via layanan aksesibilitas).
- **Pilihan metode mematikan layar** — Otomatis / Device Admin / Aksesibilitas / Overlay (tersimpan di DataStore).
- **QS Tile "Sleep Timer"** (mulai/berhenti + sisa waktu) dan **2 widget**: Matikan Layar & Sleep Timer.
- Tab baru "Aplikasi" + kartu pengingat izin "Alarm & pengingat".
- Logo/ikon baru (bulan + Zz) + monochrome untuk themed icons Android 13+.

## Upgrade dari v0.1

Install di atas APK lama langsung bisa (sama applicationId `com.zscreencontrol`).

## Instal & izin (khusus ColorOS/OPPO A5 2020)

1. Aktifkan **Install unknown apps** untuk File Manager.
2. Di aplikasi: aktifkan izin di tab **Timeout Layar** sesuai kebutuhan.
3. **Optimasi baterai → Don't optimize** + **Auto-start ColorOS** aktif.
4. Tab **Jadwal**: izinkan **Alarm & pengingat** (API 31+).
5. Tab **Aplikasi**: aktifkan **Layanan Aksesibilitas**.

> APK ini ditandatangani kunci **debug** — cocok untuk pemakaian pribadi.
